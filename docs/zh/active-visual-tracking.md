# 主动视觉跟踪

✨我们使用具身视觉跟踪任务来评估具身视觉智能体在复杂动态环境中的表现。

## 简介：

具身视觉跟踪是一项具有挑战性的任务，要求智能体在3D环境中动态跟随移动目标，利用第一人称视觉并与周围环境持续交互。我们依托 UnrealZOO 平台，在真实且不断变化的条件下对智能体进行基准测试，以评估其在不同场景中的鲁棒性、适应性和泛化能力。


UnrealZoo 提供了大量照片级真实感、丰富多样的环境，作为具身AI智能体的试验场。多样的场景设置和智能体使研究人员能够将具身AI的能力推向新的高度，在超越简单室内导航的场景中进行测试。

### UnrealZoo 面向具身视觉跟踪的关键特性

- 照片级真实感动态环境：
旨在模拟一系列真实世界挑战，包括遮挡、动态光照、不规则地形和多层结构。

- 多智能体场景：
智能体必须在包含多个移动智能体和物体的动态环境中导航并跟踪目标，促进面向救援任务或监控等应用的协作跟踪。

- 可定制环境API：
我们改进的API使用户能够轻松设置复杂的跟踪任务以及智能体与其环境之间的交互，包括用于控制频率调节的时间膨胀包装器。

- 数据采集API：
用户可以使用 UnrealCV+ 直接从环境中采集视觉数据集，支持颜色、物体掩码、表面法线和深度数据的捕获。

以下是跟踪智能体在四类场景中第一人称视角的示例：

📌室内场景：

智能体需要应对频繁的低矮障碍物和狭窄通道，测试其遮挡处理和精确运动能力。

📌宫殿：

智能体面对多层结构和复杂设计，掌握空间感知能力至关重要。

📌野外：

不规则地形和变化的光照条件模拟不可预测条件下的户外跟踪。

📌现代场景：

这些高保真场景代表真实世界环境，如工厂和停车场，要求智能体适应细节丰富且密集的周围环境。
