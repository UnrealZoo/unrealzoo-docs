# 人类演示

为提供更流畅、更直观的用户体验，开发了额外的电子游戏风格可执行程序。用户可通过简单的数字键在不同智能体类型之间无缝切换，并使用键盘和鼠标控制其移动和视角。该程序无需第三方键盘映射库（如 pynupt.keyboard）。该方法提供更灵活、更动态、更真实的第一人称视角，帮助研究人员完成高质量的具身智能数据采集。

### 键盘控制说明：

1. 启动环境后，进入旁观者模式，可使用虚拟相机自由探索。
2. 按键盘上的“1”到“4”键，即可在人类、汽车、摩托车和无人机之间切换。
3. 使用“W、A、S、D”向任意方向移动。
4. 使用“E”从地板或桌子上拾取物品。
5. 驾驶无人机时，按“E”飞得更高，按“C”降得更低，并使用鼠标旋转视角。

游戏开始！
