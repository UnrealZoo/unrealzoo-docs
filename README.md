# UnrealZoo Documentation

Official documentation for [UnrealZoo](https://unrealzoo.site/): Enriching Photo-realistic Virtual Worlds for Embodied AI (ICCV 2025 Highlights).

This documentation is built with [MkDocs](https://www.mkdocs.org/) + [Material for MkDocs](https://squidfunk.github.io/mkdocs-material/), and is designed to be hosted on [Read the Docs](https://readthedocs.org/).

## Structure

- `docs/` — Markdown documentation (AI-writable, version-controllable)
- `docs/assets/` — images
- `mkdocs.yml` — site configuration and navigation

## Local preview

```bash
pip install mkdocs-material
mkdocs serve
```

Open http://127.0.0.1:8000.

## Build

```bash
mkdocs build
```

## Contributing

The docs are authored in Markdown. Edit files under `docs/` directly, or let an AI agent read/write them. Each page is a single Markdown file, making it easy to version-control and scale.
